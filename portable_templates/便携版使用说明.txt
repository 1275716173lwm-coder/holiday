国航预占助手便携版

适用环境：64 位 Windows 10/11，电脑已安装 Microsoft Edge。
本便携版已内置 Node.js 和 playwright-core，不需要安装 Node.js，也不需要执行 npm install。

首次使用：
1. 将整个“国航预占助手便携版”文件夹解压到本机普通目录，不要直接在压缩包内运行。
2. 双击“启动国航预占助手.cmd”。
3. 在助手中点击“重新登录”，在专用 Edge 中完成登录。
4. 登录成功后即可保存设置、只填表或使用等待开放自动提交。

迁移说明：
- 登录 Cookie、密码和验证码不会打包；每台新电脑都必须重新登录。
- 登录状态仅保存在当前电脑的 %LOCALAPPDATA%\AirChinaWebAutomation\edge-profile。
- airchina_config.json 包含姓名、员工号和当前请假设置，请妥善保管压缩包。
- 定时任务运行期间电脑必须保持开机、联网、未休眠，且不要结束助手后台进程。
- 所有自动操作完成或发生错误后，专用 Edge 保持打开，由人工关闭。

常用入口：
- 启动国航预占助手.cmd：推荐入口，可视化设置全部功能。
- 网页登录.cmd：单独打开重新登录流程。
- 网页填表.cmd：只填表，永不自动提交。
- 网页刷新填表并提交.cmd：按配置等待开放并自动提交。

安全说明：
- 自动提交必须同时满足配置中的自动提交开关和专用提交入口授权。
- “强制请假”只会使用预选日期中的可用日期，不会补选其他日期。
- 请勿将包含个人配置的压缩包发送给无关人员。
